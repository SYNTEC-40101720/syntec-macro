> 本文件为 [新代 MACRO 语法规范手册](../新代MACRO语法规范手册.md) 的拆分子主题（子程序与宏呼叫）。

## 5. 子程序与宏呼叫

状态：已确认 / 部分待确认

### 5.1 呼叫方式

```iecst
M98 P1000 H2 L1;
G65 P1000 L1 X100. Y50. A20.;
G66 P1000 L1;
G66.1 P1000 L1;
G67;
M99;
M99 P100;
M99 Q20;
```

| 语法 | 类型 | 区域变量行为 | 说明 |
| --- | --- | --- | --- |
| `M98 P_ H_ L_` | 子程序 | 继承主程序 `#1` ~ `#400` | `P`=副程序名，`H`=起始序号，`L`=重复次数 |
| `G65 P_ L_` | 宏程序 | 独立的 `#1` ~ `#400`，引数写入 `#1` ~ `#26` | 非模态呼叫 |
| `G66 P_ L_` | 模态宏程序 | 独立的 `#1` ~ `#400`，`G66` ~ `G67` 期间共用 | 移动指令触发呼叫 |
| `G66.1 P_ L_` | 模态宏程序 | 与 `G66` 相同 | 每单节触发呼叫 |
| `G_` 扩充 G 码 | 宏程序 | 每次创建新的 `#1` ~ `#400` | 例如 `G200`、`G500` |
| `M_` M 码宏程序 | 宏程序 | 每次创建新的 `#1` ~ `#400` | 需在 `Pr3601` 起登录 |
| `T_`，`Pr3215=2` | T 码宏程序 | 每次创建新的 `#1` ~ `#400` | T 码宏程序 |
| `T_`，`Pr3215=1` | T 码副程序 | 继承主程序 `#1` ~ `#400` | T 码副程序 |

规则：

- `L` 引数未指定时，系统默认 `L=1`。
- `G67` 取消 `G66` / `G66.1` 模态宏程序。
- `M96/M97` 为中断程序启用/取消。

### 5.2 返回方式

状态：已确认

| 语法 | 说明 |
| --- | --- |
| `M99;` | 返回主程序，从呼叫处下一行继续 |
| `M99 P_;` | 返回主程序的指定序号 `N_` 位置 |
| `M99 Q_;` | 返回主程序的指定行号位置 |
| `G67;` | 取消 `G66` / `G66.1` 模态宏程序 |

待确认：

- `M198 H_` 与 `M98 H_` 具体语义是否完全一致。
- `G65 P"Name"` 字符串宏名跳转规则和大小写规则。

### 5.3 登录 G / M / T 码宏程序

状态：已确认 / 部分版本差异

控制器提供扩充 G 码、登录 G 码、登录 M 码、T 码宏程序四种宏程序机制。

| 类型 | 编号范围 | 是否需要参数登录 | 登录参数 | 档案命名 |
| --- | --- | --- | --- | --- |
| 扩充 G 码 | `G200` ~ `G999` | 不需要 | 无 | `G0200`、`G200001` |
| 登录 G 码 | 既有标准 G 码 | 需要 | `Pr3701` ~ `Pr3710` | `G0000`、`G0001` 等 |
| 登录 M 码 | `M0` ~ `M9999` | 需要 | `Pr3601` ~ `Pr3610` | `M0050`、`M0123` 等 |
| T 码宏程序 | T 码 | 需要 | `Pr3215` | 固定 `T0000` |

#### 5.3.1 扩充 G 码

状态：已确认

扩充 G 码用于机械厂自行新增 G 码功能，不覆盖标准 G 码，无须参数登录，只要无后缀文件存在即可呼叫。

| 呼叫 | 文件名 | 说明 |
| --- | --- | --- |
| `G200` | `G0200` | 4 字命名 |
| `G200.1` | `G200001` | 6 字命名 |
| `G200.10` | `G200010` | 6 字命名 |
| `G999` | `G0999` | 4 字命名 |

规则：

- 文件名不可带后缀。
- 每次呼叫都会创建新的独立 `#1` ~ `#400` 区域变量空间。
- `L` 引数可用于重复执行，例如 `G200 L3 X10.;`。

#### 5.3.2 登录 G 码

状态：已确认 / 部分版本差异

登录 G 码用于将既有标准 G 码改由自定义宏程序取代。登录后，程序执行到对应 G 码时，不再执行原标准 G 码动作，而是执行对应宏程序。

参数规格：

| 版本 | 参数 | 说明 | 范围 | 初始值 | 生效时机 |
| --- | --- | --- | --- | --- | --- |
| V10 | `Pr3701` ~ `Pr3710` | 登录 G 码呼叫宏程序 | `-1` ~ `13` | `0` | 重新开机 |
| V12 | `P10301` ~ `P10310` | 登录 G 码呼叫宏程序 | N1~N4 | | |

设定值对照：

| 设定值 | 标准 G 码 | 宏程序文件 |
| --- | --- | --- |
| `0` | 不启用 | - |
| `-1` | `G00` | `G0000` |
| `1` | `G01` | `G0001` |
| `2` | `G02` | `G0002` |
| `3` | `G03` | `G0003` |
| `4` | `G53` | `G0053` |
| `5` | `G40` | `G0040` |
| `6` | `G41` | `G0041` |
| `7` | `G42` | `G0042` |
| `8` | `G43` | `G0043` |
| `9` | `G44` | `G0044` |
| `10` | `G49` | `G0049` |
| `11` | `G04` | `G0004` |
| `12` | `G02.4` | `G2004` |
| `13` | `G03.4` | `G3004` |

规则：

- 登录 G 码宏程序视同 G 码宏程序特性，每次呼叫创建独立 `#1` ~ `#400`。
- 登录 G 码宏程序内部的所有 G 码均为标准 G 码。
- 标准插值 G 码登录客制后仍具有继承功能，例如客制 `G00` 后，下一行无显式插值码时可能继承执行。
- 若登录宏程序中改变 `#1000` 插值模式，离开前应还原。
- 登录 G 码与标准 G 码的解译顺序在 10.114.50 起相同；旧版行为不同。
- 不支援用于车床 `G7.1`、`G12.1`、车床 `,A` / `,R` / `,C`、车铣加工循环指令、T 码宏程序等场景。

```iecst
// 参数设定示例
Pr3701 = -1  // 客制 G00 -> G0000
Pr3702 = 1   // 客制 G01 -> G0001
Pr3703 = 2   // 客制 G02 -> G0002
Pr3704 = 3   // 客制 G03 -> G0003
```

#### 5.3.3 登录 M 码

状态：已确认 / 部分版本差异

参数规格：

| 版本 | 参数 | 说明 | 范围 | 初始值 | 生效时机 |
| --- | --- | --- | --- | --- | --- |
| V10 | `Pr3601` ~ `Pr3610` | 登录 M 码呼叫宏程序 | `0` ~ `99999999` | `0` | 重新开机 |
| V12 | `P10201` ~ `P10210` | 登录 M 码呼叫宏程序 | N1~N4 | | |

规则：

- `Pr3601` ~ `Pr3610` 设为 `0` 时，不呼叫 `Mxxxx` 宏程序，直接进入 PLC 触发动作。
- 参数非 `0` 时，先呼叫对应 `Mxxxx` 宏程序，再依据宏程序内容决定是否进入 PLC 触发动作。
- 文件名为 `M` + 4 位数字，例如 `M123` -> `M0123`、`M50` -> `M0050`、`M1601` -> `M1601`。
- 文件名不可带后缀。
- 系统内定 M 码不可登录，包括 `M00`、`M01`、`M02`、`M30`、`M96`、`M97`、`M98`、`M99`。
- Pr3601 起登录的 M 码宏程序内，无法再呼叫其余 M 码或 T 码宏程序，而是直接触发 PLC 对应动作。
- 现况 Pr3601 起仅支援设定范围 `0` ~ `9999`，登录组数 10 组。
- 不可与 `Pr3599`、`Pr3600`、`Pr3804`、`Pr3742/3743`、`Pr3763` 等 M 码相关参数重复，否则触发 `OP-020` M 码相关参数设定冲突。

```iecst
Pr3601 = 123  // 登录 M123 -> M0123
Pr3602 = 124  // 登录 M124 -> M0124
Pr3603 = 50   // 登录 M50  -> M0050
```

M 码宏程序引数占用：

- M 码宏程序执行完毕后，会占用除 T 码以外的所有引数。
- 即使宏程序内只读取部分引数，执行完毕后所有引数，除 T 外，均被视为已占用。
- M 码作为宏程序或引数时，`#13` 会更新，但 R 值不更新；M 码作为辅助码时，`#13` 与 R 值均更新。

#### 5.3.4 T 码宏程序

状态：已确认

| `Pr3215` | 行为 | 呼叫类型 | 区域变量 |
| --- | --- | --- | --- |
| `0` | 不呼叫副程序 | - | - |
| `1` | 呼叫 `T0000` 作为副程序 | 子程序 | 继承主程序 `#1` ~ `#400` |
| `2` | 呼叫 `T0000` 作为宏程序 | 宏程序 | 每次创建独立 `#1` ~ `#400` |

规则：

- 文件名固定为 `T0000`，不可带后缀。
- 在副程序内的 T 码为普通 T 码，不会再呼叫 `T0000`。
- T 码宏程序不受 `L` 引数影响。

#### 5.3.5 同一单节解译与引数占用

状态：已确认 / 部分版本差异

解译优先级：

| 优先级 | 内容 |
| --- | --- |
| 1 | 扩充 G 码宏程序 / 登录 G 码 |
| 2 | M 码宏程序 / T 码宏程序 |
| 3 ~ 9 | `S` / `F` / `H` / `D` / `T` / `M` / `B` |
| 10 | 插值 G 码 / 功能 G 码 |

组合行为：

| 组合 | 行为 |
| --- | --- |
| `G200 M123 X10. Y20.;` | G200 先执行；若读取轴向引数，所有轴向引数被占用，M123 不执行 |
| `G200 M123 X10. P5.;` | G200 先执行；若仅读取 P 且 M 码未被占用，M123 会执行 |
| `M123 M124 X10.;` | 多个 M 码宏程序同一行，只执行第一个 |
| `T01 M123 X10.;` | T 码宏程序先解译；若 T 码未占用引数，M123 会执行 |
| `G200 G300 X10.;` | 多个 G 码宏程序同一行，只执行最后一个 |

引数占用规则：

| 宏程序类型 | 引数占用方式 |
| --- | --- |
| 扩充 G 码 | 仅占用宏程序实际读取的引数 |
| 登录 G 码 | 仅占用宏程序实际读取的引数 |
| M 码宏程序 | 执行后占用除 T 码以外的所有引数 |
| T 码宏程序 | 仅占用宏程序实际读取的引数 |

轴向引数连带占用：宏程序读取任一轴向引数 `X/Y/Z/A/B/C/I/J/K/U/V/W` 时，所有轴向引数一起被占用。

#### 5.3.6 Pr3598 M 码引数模式

状态：已确认 / 部分版本差异

| `Pr3598` | 行为 |
| --- | --- |
| `0` | 宏程序调用 `#13` 时，读取该单节最后一个 M 码并占用所有 M 码 |
| `1` | 已登录为宏程序的 M 码不会被当作其他宏程序的引数；`#13` 只读取第一个非宏程序 M 码 |

`Pr3598=1` 下，同一单节两个以上宏程序同时读取 M 码引数时，可能触发 `COR-371`。

#### 5.3.7 常见警报与速查

状态：已确认 / 部分版本差异

| 场景 | 警报 / 风险 |
| --- | --- |
| M 码相关参数设定重复或冲突 | `OP-020` M 码相关参数设定冲突 |
| 登录系统内定 M 码 | `OP-020` |
| 非 APP Macro 中存取 AR/MAR | `COR-016` |
| 同一单节两个以上宏程序同时读取 M 码引数，`Pr3598=1` | `COR-371` |
| 登录 G 码宏程序内使用车/铣床加工循环 | 无法运作 |
| 登录 G 码内改变 `#1000` 未还原 | 离开宏程序后状态错乱 |

扩充 G 码与登录 G 码对比：

| 特性 | 扩充 G 码 `G200` ~ `G999` | 登录 G 码 `Pr3701` 起 |
| --- | --- | --- |
| 用途 | 新增全新 G 码功能 | 替换 / 客制既有标准 G 码 |
| 是否需要登录 | 不需要 | 需要 `Pr3701` ~ `Pr3710` |
| 档名范围 | `G0200` ~ `G0999` / 6 字命名 | `G0000`、`G0001` 等 |
| 解译优先级 | 与模态 G 码同级 | 10.114.50 起与标准 G 码同级 |
| 程序内 G 码 | 标准 G 码 | 标准 G 码 |
| 插值模式继承 | 不继承 | 继承，例如 `G00/G01` |
| `L` 引数 | 支援，作为重复次数 | 不适用 |
