> 本文件为 [新代 MACRO 语法规范手册](../新代MACRO语法规范手册.md) 的拆分子主题（MACRO 语法指令）。

## 4. MACRO 语法指令

### 4.1 语法总览

状态：已确认

| 语法 | 用途 | 结尾符号 |
| --- | --- | --- |
| 变量指定 | 赋值 | `;` |
| `GOTO` | 跳转到指定 `N` 行号 | `;` |
| `IF` | 条件判断 | `END_IF;` |
| `CASE` | 多条件分支 | `END_CASE;` |
| `REPEAT` | 后测试循环，至少执行一次 | `END_REPEAT;` |
| `WHILE` | 前测试循环，可能不执行 | `END_WHILE;` |
| `FOR` | 计数循环 | `END_FOR;` |
| `EXIT` | 中断并跳离循环 | `;` |
| 程序注释 | 单行或区块注释 | 行尾或 `*)` |
| 巢状语法 | 多层嵌套 | 对应结尾符号 |

### 4.2 变量指定

状态：已确认

```iecst
<变量> := <叙述>;
```

规则：

- 直接定值支援区域变量、公用变量、APP 变量与 APP 永久变量。
- 间接定值使用中括号 `[ ]`，不是小括号 `( )`。
- 字符串写入不同变量区时会依变量类型产生不同储存行为。

```iecst
@1 := 123;
#1 := 456;
AR1 := 789;
MAR1 := 789;

#10 := "12";  // 区域变量 #10 内容为 12
@10 := "12";  // 公用变量 @10 内容为 ASCII 转码值

#1 := 123;
@[#1] := 567;      // 等同 @123 := 567
@[#1 + 7] := 890;  // 等同 @130 := 890
AR[#1] := 789;     // 等同 AR123 := 789
MAR[#1] := 789;    // 等同 MAR123 := 789
```

### 4.3 GOTO

状态：已确认

```iecst
GOTO n;
```

规则：

- `GOTO` 的目标是 `N` 行号，不是程序行数。
- 可使用变量作为跳转目标，例如 `GOTO #2;`。
- 若程序中存在两个相同 `N` 行号，以第一个为准。
- 使用 `GOTO` 时应避免无穷循环；必要时在循环中加入 `SLEEP()`，让人机仍有机会中止程序。

```iecst
%@MACRO
#1 := 1;
#2 := 10;

IF #1 = 1 THEN
  GOTO #2;
END_IF;

IF #1 = 2 THEN
  GOTO 100;
END_IF;

N10;
G01 G90 X50. Y0. F1000;
M30;

N100;
G01 G90 X0. Y50. F1000;
M30;
```

### 4.4 IF

状态：已确认

```iecst
IF <条件> THEN
  <陈述列表>
ELSEIF <条件> THEN
  <陈述列表>
ELSE
  <陈述列表>
END_IF;
```

规则：

- 支持 `ELSEIF`。
- `ENDIF` 可兼容识别，但建议使用 `END_IF`。
- 不支持 `ELSIF`，插件报 error。
- 单档 IF 组数上限为 256 组；扩充版本为 512 组。
- 单组 `ELSEIF` 数量上限新版为 512 个，旧版为 16 个。

相关警报：

| 警报 | 触发条件 |
| --- | --- |
| `COM-019` | 遗漏 `IF ... THEN` 语句 |
| `COM-020` | 缺少 `END_IF`，有 `ELSEIF` 无 `ELSE` |
| `COM-021` | 缺少 `END_IF`，有 `ELSE` |
| `COM-030` | IF 组数超过上限 |
| `COM-005` | `ELSEIF` 数量超过上限 |

### 4.5 CASE

状态：已确认

```iecst
CASE <条件变量> OF
<值>:
  <陈述列表>
<值>,<值>:
  <陈述列表>
ELSE
  <陈述列表>
END_CASE;
```

规则：

- 条件值必须为大于等于 0 的整数 Long 型态。
- 多个值可用逗号分隔，例如 `3, 4, 5:`。
- `ELSE` 分支可选。
- 默认分支只支持 `ELSE`，不支持 `DEFAULT`。
- `ENDCASE` 可兼容识别，但建议使用 `END_CASE`。
- 分支标签后同行陈述可识别但不推荐，建议分支标签独占一行。
- 单档 CASE 组数上限为 256 组；扩充版本为 512 组。
- 单组条件语句 `:` 数量上限新版为 512 个，旧版为 16 个。

相关警报：

| 警报 | 触发条件 |
| --- | --- |
| `COM-022` | 遗漏 `CASE ... OF` 语句 |
| `COM-023` | 缺少 `ELSE` 或 `END_CASE` |
| `COM-024` | 有 `ELSE` 但缺少 `END_CASE` |
| `COM-025` | 缺少含 `:` 的条件语句 |
| `COM-029` | CASE 组数超过上限 |
| `COM-005` | 条件语句数量超过上限 |

### 4.6 REPEAT

状态：已确认

```iecst
REPEAT
  <陈述列表>
UNTIL <条件> END_REPEAT;
```

规则：

- `REPEAT` 是后测试循环，先执行一次循环体，再判断条件，至少执行一次。
- `ENDREPEAT` 可兼容识别，但建议使用 `END_REPEAT`。
- 单档上限为 256 组；扩充版本为 512 组。

相关警报：

| 警报 | 触发条件 |
| --- | --- |
| `COM-034` | 遗漏 `REPEAT` |
| `COM-015` | 遗漏 `UNTIL ...` 语句 |
| `COM-016` | 缺少 `END_REPEAT` |
| `COM-031` | REPEAT 组数超过上限 |

### 4.7 WHILE

状态：已确认

```iecst
WHILE <条件> DO
  <陈述列表>
END_WHILE;
```

规则：

- `WHILE` 是前测试循环，先判断条件，条件成立才执行，可能一次都不执行。
- `ENDWHILE` 可兼容识别，但建议使用 `END_WHILE`。
- 单档上限为 256 组；扩充版本为 512 组。

相关警报：

| 警报 | 触发条件 |
| --- | --- |
| `COM-017` | 遗漏 `WHILE ... DO` 语句 |
| `COM-018` | 缺少 `END_WHILE` |
| `COM-032` | WHILE 组数超过上限 |

### 4.8 FOR

状态：已确认

```iecst
FOR <变量> := <起始值> TO <终止值> BY <步进值> DO
  <陈述列表>
END_FOR;
```

规则：

- `ENDFOR` 可兼容识别，但建议使用 `END_FOR`。
- 单档上限为 256 组；扩充版本为 512 组。
- 不建议在 `FOR` 循环内使用会跳转进出循环的命令，包括复式切削循环 `G72` ~ `G78`、跳出循环再跳回的 `GOTO`、`M98 H_`。
- 上述跳转行为可能导致 `BY` 步进值异常。

```iecst
%@MACRO
FOR #10 := 1 TO 100 BY 1 DO
  GOTO 12;
  N13;
END_FOR;
M30;

N12;
M00;
@1 := @1 + 5;
GOTO 13;
M99;
```

相关警报：

| 警报 | 触发条件 |
| --- | --- |
| `COM-013` | 遗漏 `FOR ... DO` 语句 |
| `COM-014` | 缺少 `END_FOR` |
| `COM-033` | FOR 组数超过上限 |

### 4.9 EXIT

状态：已确认

```iecst
EXIT;
```

规则：

- `EXIT` 用于在 `REPEAT`、`WHILE`、`FOR` 循环内部提前跳出循环。
- `EXIT` 不影响块栈配对。

### 4.10 注释

状态：已确认

```iecst
G00 G90 X0. Y0.;  // 移动回原点

(*
此区块为注释区
*)
```

规则：

- `//` 后面到行尾的内容均为注释。
- `(* ... *)` 之间的内容为区块注释，可跨多行。
- ISO 格式使用 `( ... )` 作为注释；MACRO 格式使用 `(* ... *)`，两者不同。

### 4.11 巢状语法

状态：已确认

规则：

- `CASE`、`IF`、`REPEAT`、`WHILE`、`FOR` 可以互相嵌套。
- 巢状上限为 10 层。
- 超过 10 层会触发 `COM-007` 重覆回圈太深。
- 建议使用空格或 Tab 缩排，提升可读性。

### 4.12 循环选择

状态：已确认

| 特性 | `REPEAT ... UNTIL` | `WHILE ... DO` | `FOR ... TO ... BY ... DO` |
| --- | --- | --- | --- |
| 测试时机 | 后测试 | 前测试 | 前测试 |
| 最少执行次数 | 1 次 | 0 次 | 0 次 |
| 适用场景 | 至少执行一次的操作 | 条件不确定时 | 已知循环次数 |
| 计数器 | 手动管理 | 手动管理 | 自动管理，依 `BY` 步进 |
| 条件位置 | `UNTIL` 后，循环末尾 | `WHILE` 后，循环开头 | `TO` 后，循环开头 |

### 4.13 分号规则

状态：已确认 / 部分版本差异

| 版本 | 行尾缺少分号的行为 |
| --- | --- |
| 10.120.45 之前 | 与下一行合并处理，若合并后合法则正常执行 |
| 10.120.45 ~ 10.120.60 | 跳出 `COM-008` 子句中没有结束的符号 `;` |
| 10.120.61 之后 | 回到与下一行合并处理的行为 |

不需要分号的语法：

- `IF ... THEN`
- `ELSEIF ... THEN`
- `ELSE`
- `WHILE ... DO`
- `FOR ... DO`
- `REPEAT`
- `CASE ... OF`
- `N:` 条件标签行

### 4.15 无穷循环防护

状态：已确认

规则：

- `REPEAT`、`WHILE`、`FOR`、`GOTO` 都有无穷循环风险。
- 无穷循环可能造成人机画面锁死、加工程序卡死。
- 循环中可适时加入 `SLEEP()`，即使误入无穷循环，仍有机会操作人机画面中止程序执行。
