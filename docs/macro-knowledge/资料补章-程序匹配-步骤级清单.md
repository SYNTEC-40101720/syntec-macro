## Phase β — 静态诊断规则对齐（中风险，新增 warning，避免误报）

**总目标**: 把补章中「静态可判、跨版本稳定、误报成本低」的规则补进 `src/robotValidator.js` / `src/validator.js` / `src/diagnosticCodes.js`，注册对应 `SYNTEC_*` 诊断 code 并登记 `src/diagnosticActions.js` 修复动作。

### β.1 G10 L1802 静音模式版本门控 warning

- 入口：
  - `src/robotValidator.js` 新增对 `G10 L1802 P_` 的解析逻辑
  - `src/diagnosticCodes.js` 新增 `SYNTEC_ROBOT_G10_L1802_SILENT_VERSION_GATE`
  - `src/diagnosticActions.js` 注册对应 code action
- 规则：当前文件上下文出现 `#1500 := 1` 或 `#1820` 非零赋值（最近一次赋值的状态，避免跨 G65/G66 边界推断）后跟随 `G10 L1802 P_` 时，emit warning「静音模式下静音模式 `10.118.40R/42R/48C/50+` 版本族不支援 L1802」。
- 依据：`docs/macro-handbook/05-robot.md` §8.4.3 补章段 + 02-variables.md §2.7.1 (`#1500` bit0 / `#1820` 值映射)。
- 验收：新增 `tests/robotValidator.test.js` 用例：1) 无 `#1500 := 1` / 无 `#1820` 赋值时不触发；2) 仅 `#1500 := 1` 不触发（仍只在 L1802 行 lint）；3) 同时存在静音赋值 + L1802 行 → warning；4) `#1500 := 0` 在 L1802 前 → 不触发。
- 阻塞：无。
- 风险：中。需注意 `#1500` 在 G65/G66 调用边界外的污染不应被父文件推断——只取调用边界内最近一次赋值状态；若上下文无法精确确定状态，**不 emit**（避免误报），改为 hover 提示。
- 状态：✅ 已完成（2026-09-21）。新增 `SYNTEC_ROBOT_G10_L1802_SILENT_VERSION_GATE` code 与 code action；`src/robotValidator.js` 加 `silentModeActive`/`l1802WarnedLines`状态字段 + 解析 `#1500`/`#1820` 赋值 + 对 L1802 行 emit warning。采用文件级最近一次赋值保守 emit，`#1500:=0` 后复位。`tests/validator.test.js` 新增 5 个 L1802 场景测试。
