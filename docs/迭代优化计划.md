# 迭代优化计划

> 主流程已在 v4.0.0 (2026-09-22) 收口. 本文件是后续接续工作的简明交接清单; 详细已完成历史节点见 `CHANGELOG.md`, 详细实施参考 `docs/R1.2-实施方案.md` (Rollback 用).

## 当前架构 (v4.0.0 起)

插件分析后端**硬切为 rust-wasm 唯一**:

- 12 个 JS 分析器模块已从仓库删除 (analysisCore/lexer/validator/robotValidator/controlFlowValidator/functionArgumentValidator/diagnosticRules/diagnosticFactory/formatter/navigationSymbols/navigationIndex/statementClassifier), 净减 ~4218 行.
- `syntecMacro.analysisBackend` enum 收敛为 `['rust-wasm']` 单值; `javascript` / `rust-wasm-shadow` 配置值退役 (VS Code 枚举校验拒绝旧值并提示重设为 `rust-wasm`).
- Host provider (completion/hover/definition/navigation/formatting/diagnostics/code-actions) 走 `hostRustAnalyzer` 同步路径; Worker 硬切 rust-wasm.
- 数据真源 5 个 JS 表 (keywords/codeDocs/functions/systemVariables/completionSnippets) 保留, 留给 Phase R2 迁到 JSON.

发布: GitHub Release <https://github.com/SYNTEC-40101720/syntec-macro/releases/tag/v4.0.0>, VSIX 240510 B, SHA-256 `4d1e53313093bfed41bc40124d5abe08f54933caadeca4cae829d725c46dfef5`.

## 后续计划 (v4.x+)

按优先级:

1. **Phase R2 数据表迁移** — 中优先. 把 5 个 JS 数据真源 (`src/keywords.js` / `src/codeDocs.js` / `src/functions.js` / `src/systemVariables.js` / `src/completionSnippets.js`) 迁到 `src/data/*.json` + loader, 让 host 与 Rust 从同一 schema 读, 消除两端重复维护. 详见 `docs/JS-Backend退役路线图.md` §Phase R2.
2. **R1.3 VSIX 体积与启动基线刷新** — 低优先. 采集 `perf-baseline/v4.0.0.json` 作退役后节点基线, 供后续回归对照. `perf-baseline/README.md` 记录采集规则.
3. **Phase 5 控制器实测证据采集** — 证据阻塞. 取得 CNC 模拟器/控制器环境后采 CALL-RUN-01..07 / GETPR/SETPR (FUN-A-13) / ROB-LTP-01..08. 详见 `docs/macro-knowledge/Phase5-控制器证据采集清单.md`. 不阻塞代码工作.
4. **新诊断规则科学化** — 可选. 68/68 Rust parity code 已全覆盖, 后续诊断增改走 "规范手册 + 能力矩阵 + Rust monomorph + 单测" 四件套, 关键词新增仅扩 `keywords.js`.
5. **v5.0 Major 远期** — 仅在 R2 收口后评估是否还要进一步精简 host 配置面与硬假设为 Rust-only.
