## 1. 默认 backend 切换决策门 — Rust 收益评估

**目标**: 让 Rust/Wasm backend 稳定优于 JS，再发下一个 Minor release 切换默认 backend。

**为什么没切**: v3.0.0 实测 `npm.cmd run benchmark:compare -- --iterations 5` 在 large-20k 上 JS p50 422ms vs Rust 457ms 仍存微弱回归，按 `docs/3.x-Rust-Wasm切换剩余任务规划.md` §3 禁令 1 不得强行切换。

**何时可切**:
- 在 dev machine (Windows) 与 CI (Linux + Windows) 上各跑 `npm.cmd run benchmark:compare -- --iterations 10`，三场景（fixture / 20k / nav-500-files）Rust p50 / p95 / max 都不少于 JS（误差 ≤ 5%）。
- `fallback` 比例持续 0%（已采集 5 次以上）。
- `workerLifecycle.test.js` 9 项集成测试无新增 FAIL。
- 更新 `scripts/benchmarkCompare.js` 的 `REGRESSION_THRESHOLDS`，把 Rust 阈值改为等于或严于 JS 阈值后跑 `npm.cmd run check:release:readiness -- --strict` 仍全 PASS。

**入口**: `scripts/benchmarkCompare.js` + `scripts/comparePerfData.js` + `tests/benchmarkCompare.test.js` + `tests/comparePerfData.test.js`。

## 2. Rust 跨行状态 parity — LTP / 机器人 / Modbus 生命周期

**目标**: 把目前 JS 只记录证据不静态强制的跨行规则，迁到 Rust 侧并 parity 校验。

**为什么没做**: 跨行状态、运行时生命周期、`WAIT()` 时序、模式宏触发等需要控制器实测证据，仅靠静态解析不准（参见 `docs/macro-knowledge/MACRO-LTP专项资料包.md`）。

**关键资料阻塞**:
- `CALL-RUN-01` 到 `CALL-RUN-07` 调用语义资料包需要模拟器/控制器环境验证变量生命周期、`M198` 重读、`WAIT()` 时序。
- `GETPR/SETPR` 需要直接的 A 级函数页或记录化控制器验证。

**入口**: `docs/macro-knowledge/MACRO调用语义资料包.md` + `docs/macro-knowledge/MACRO-LTP专项资料包.md` + `src/robotValidator.js` 注释。

## R. JS Backend 退役路线图（v3.x → v4.0）

**目标**: 在 Rust/Wasm 稳定为单一生产 backend 后，把 JS analyzer 函数式核心（13 个文件 ~3261 行）从 VSIX 剔除，仅保留 Rust/Wasm + host-only Provider + 数据真源表，落地 v4.0 Major 退役。

**完整路线图**: `docs/JS-Backend退役路线图.md` — 含 3 项不变前提、Phase R1 (JS 核心 retire) + Phase R2 (数据表迁移 host 共享层) + Phase R3 (agent 不擅自做的事)。

**当前现态**（`audit:js-backend` 与 `check:js-backend-retirement` 一次性 review）:
- JS 端 `DiagnosticCode` 67 个，Rust 端 literal 覆盖 64，剩 3 项 `*_Q_RANGE` dead code 两端均不 emit — 待 Phase 5.3 决策两端共同剔除或共同补 emit。
- analyzer 函数式核心 14 个 JS 模块对应 Rust 实体已就位，待 R1.1 准入后一次性退役。
- 14 个 host-only Provider 文件（vscode API 绑定）+ 7 个数据真源表（keywords/codeDocs/functions 等）保留作 host 层入口，绝对不删。

**准入条件**（须全过才进 R1.2 剔除 PR）:
1. Phase 1.5 切默认 backend = `rust-wasm`，发 v3.1.0
2. ≥1 release cycle 观察期 fallback 持续 0%
3. Phase 5.x 跨行状态完整 parity（dead code 已决策）
4. `compare:rust` 与 `compare:perf` 持续等价 ≥1 release cycle
5. `check:js-backend-retirement --strict` 全 PASS

**入口工具**（agent 已就位）:
- `npm.cmd run audit:js-backend` — 表面审计输出 markdown 报告
- `npm.cmd run check:js-backend-retirement -- --strict` — R1 准入 6 项自检
