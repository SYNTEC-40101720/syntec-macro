# 新代 MACRO 语法规范手册 · 撰写陷阱

> 本文件为 [MACRO 语法手册](README.md) 的分册（撰写陷阱与最佳实践）。
> CF 检索状态以 [能力矩阵](../MACRO能力矩阵.md) 为准。

## 撰写陷阱

### 档案格式与命名

状态：已确认

| 项目 | 正确做法 | 风险 |
| --- | --- | --- |
| 格式宣告 | 第一行使用 `%@MACRO` | 否则视为 ISO 格式，MACRO 语法触发 `COM-003` |
| 扩充 G 码 | 使用无后缀 `G0200`、`G200001` | 加后缀会导致控制器无法按扩充 G 码规则查找 |
| O 码副程序 | 使用无后缀 `O8000`、`O0010` | 加后缀会导致副程序查找不一致 |
| 一般加工档 | 使用 `.nc`、`.cnc`、`.tap` 等加工档后缀 | 后缀不决定 MACRO 格式，仍需看首行 |
| 系统 MACRO | 放在 `DiskC:\OpenCNC\MACRO` | 人机中不可编辑 |
| APP Macro | 放在 `DiskC:\app\%AppName%\bin\Macro\` | 只有该路径可存取 AR/MAR |

### 预解与 WAIT

状态：已确认

核心会预解 MACRO 内容，变量运算速度会超前于 G/M 码实际运动执行。读取运动后的座标、状态或系统变量前，应使用 `WAIT()` 同步。

```iecst
%@MACRO
G01 X100. F500;
WAIT();
#1 := #1321;
G01 X(#1 + 50.);
M30;
```

规则：

- `WAIT()` 可等待前方 G/M 码执行完成后再继续解译。
- `M98`、`M99`、`M198` 不受 `WAIT()` 影响。
- 运动后立即读取机械座标或状态时，省略 `WAIT()` 容易读到旧值。

### 模态备份与还原

状态：已确认

MACRO 内部若改变 `G90/G91`、`G40/G41/G42` 等模态 G 码，离开 MACRO 后不会自动还原，会影响父程序后续执行。

常用模态系统变量：

| 系统变量 | 对应模态 | 说明 |
| --- | --- | --- |
| `#1000` | 插值模式 | `G00/G01/G02/G03` |
| `#1003` | 绝对/增量 | `G90/G91` |
| `#1004` | 绝对/增量 | `G90/G91` |
| `#1015` | 刀具补偿 | `G40/G41/G42` |
| `#1016` | 刀长补偿 | `G43/G44/G49` |

```iecst
%@MACRO
#10 := #1004;
#11 := #1015;

G91 G00 Y10.;
G41 D1;

G40;
G#10;
M99;
```

G 码宏程序返回前还原状态示例：

```iecst
// Main
G90;
G01 X10. F100.;  // X=10
G200;            // 呼叫 G0200，X 增量移动 10，执行后 X=20
X-20.;           // G0200 已还原 G90/G01，因此此行按主程序预期执行
M30;

// G0200
%@MACRO
#101 := #1000;   // 备份插值模式 G00/G01/G02/G03/G33/G34/G35
#102 := #1004;   // 备份 G90/G91
G91 G00 X10.;
G#101;           // 还原插值模式
G#102;           // 还原 G90/G91
M99;
```

### 座标系统禁忌

状态：已确认

| 禁止或慎用项目 | 原因 | 建议做法 |
| --- | --- | --- |
| `G92` | 图形模拟功能可能失效 | 改用 `G91` 相对移动 |
| `G54` ~ `G59` | 影响父程序工件座标系 | 进入前备份，离开前恢复；能避免则避免 |
| `G52` | 影响父程序局部座标系 | 改用增量移动或显式还原 |

### 引数处理

状态：已确认

规则：

- 长度或角度引数运算前建议使用 `STD` 标准化。
- 未传入的引数为 VACANT，应以 `#0` 判断并设定默认值。
- 轴向引数 `X/Y/Z/A/B/C/I/J/K/U/V/W` 只要一个被某宏程序占用，其余轴向引数会一起被占用。
- `L` 未指定时系统自动补 `L=1`；`L=0` 时宏程序不执行；`L=3` 时连续执行 3 次。
- 同一行不建议同时写会争用引数的 G 码宏程序和 M 码宏程序。

```iecst
IF #24 = #0 THEN
  #24 := 0.;
END_IF;

IF #9 = #0 THEN
  #9 := 1000.;
END_IF;

#27 := STD(#24);
#28 := STD(#25);
```

引数让宏程序通用化示例：

```iecst
// Main
G90 G00 X0. Y0.;
G200;       // 固定切削 10 单位正方形
G201;       // 固定切削 20 单位正方形
G202 X30.;  // 使用 X 引数指定任意边长
M30;

// G0200
%@MACRO
#101 := #1000;
#102 := #1004;
G91 G01 X10.;
G91 G01 Y10.;
G91 G01 X-10.;
G91 G01 Y-10.;
G#101;
G#102;
M99;

// G0201
%@MACRO
#101 := #1000;
#102 := #1004;
G91 G01 X20.;
G91 G01 Y20.;
G91 G01 X-20.;
G91 G01 Y-20.;
G#101;
G#102;
M99;

// G0202
%@MACRO
#101 := #1000;
#102 := #1004;
#103 := #24;  // X 引数作为正方形边长
G91 G01 X#103;
G91 G01 Y#103;
G91 G01 X-#103;
G91 G01 Y-#103;
G#101;
G#102;
M99;
```

### 变量使用建议

状态：已确认

| 需求 | 建议 |
| --- | --- |
| MACRO 内部暂存与计算 | 优先使用区域变量 `#1` ~ `#400` |
| 跨 MACRO 短期交换 | 优先使用模态变量 `#2001` ~ `#2100`、`#3001` ~ `#3100` |
| 较长生命周期共享 | 使用公用变量 `@1` ~ `@400` |
| 断电保存 | 使用 `@656` ~ `@999`、`@1001` ~ `@1999` |
| 默认初始值 | 使用客制参数 `#4001` ~ `#5500` |

客制参数对应：

| 变量范围 | 对应参数 | 说明 |
| --- | --- | --- |
| `#4001` ~ `#4100` | `Pr4001` ~ `Pr4100` | 使用者参数，只读 |
| `#4101` ~ `#4200` | `Pr4101` ~ `Pr4200` | 使用者参数，只读 |
| `#5001` ~ `#5100` | `Pr5001` ~ `Pr5100` | 使用者参数，只读 |
| `#5101` ~ `#5200` | `Pr5101` ~ `Pr5200` | 使用者参数，只读 |
| `#5201` ~ `#5500` | `Pr5201` ~ `Pr5500` | 使用者参数，只读 |

### 运算与型态陷阱

状态：已确认

```iecst
#1 := 1 / 2;         // 结果 0，整数除整数
#1 := 1. / 2;        // 结果 0.5
#1 := 1 / 2.0;       // 结果 0.5
#1 := (1/2) * 1.0;   // 结果 0.0
#1 := (1./2) * 1.0;  // 结果 0.5

#2 := 10 MOD 3;      // 合法
#2 := 10. MOD 3;     // COR-054 风险
```

规则：

- 除法至少让分子或分母带小数点，避免整数截断。
- `MOD` 仅适用于 Long 型态。
- 括号内表达式会先计算，括号内若发生整数截断，后续乘以 Double 也无法恢复精度。

### 循环与格式

状态：已确认

规则：

- `WHILE`、`REPEAT`、`FOR`、`GOTO` 都有无穷循环风险，循环中建议适时加入 `SLEEP()`。
- 不要在 `FOR` 循环内使用跳转进出循环的命令，包括往返 `GOTO`、复式切削循环 `G72` ~ `G78`、`M98 H_`。
- `IF/CASE/WHILE/FOR/REPEAT` 嵌套上限为 10 层，超过会触发 `COM-007`。
- 使用空格或 Tab 缩排，提高可读性。
- MACRO 格式注释使用 `//` 或 `(* ... *)`，不要与 ISO 的 `( ... )` 注释混用。

需要分号的语法：变量赋值、G/M 码指令、`GOTO`、`EXIT`、`END_IF`、`END_FOR` 等结尾语句。

不需要分号的语法：`IF ... THEN`、`ELSEIF ... THEN`、`ELSE`、`WHILE ... DO`、`FOR ... DO`、`REPEAT`、`CASE ... OF`、`N:` 条件标签行。

### 调试与排查

状态：已确认 / 部分版本差异

| 现象 | 可能原因 | 排查方向 |
| --- | --- | --- |
| 变量值不正确 | 预解导致读取时机错误 | 加 `WAIT()` |
| 宏程序不执行 | 引数被同一行其他宏程序占用 | 拆成多行 |
| 人机锁死 | 无穷循环 | 加 `SLEEP()` |
| `COM-003` | ISO 格式档使用 MACRO 语法 | 检查首行 `%@MACRO` |
| `COR-016` | 变量存取超出范围或路径不合法 | 检查变量编号和 APP Macro 路径 |
| 父程序行为异常 | MACRO 内改变模态 G 码未还原 | 进入时备份，离开前还原 |
| 图形模拟失效 | MACRO 内使用 `G92/G54/G52` 等 | 改用 `G91` 增量模式 |
| FOR 步进值异常 | FOR 内使用跳出再跳回 | 避免在 FOR 内跳转 |

常用调试手段：`MSG("...")`、`SLEEP(ms)`、写入公用变量 `@`、单节执行、观察 `D978/D979`。

### 撰写模板

状态：已确认

```iecst
%@MACRO
// 功能说明: [描述此 MACRO 的用途]
// 引数说明: X=..., Y=..., Z=..., P=..., Q=...

// 1. 引数检查与默认值
IF #24 = #0 THEN
  #24 := 0.;
END_IF;
IF #25 = #0 THEN
  #25 := 0.;
END_IF;
IF #9 = #0 THEN
  #9 := 1000.;
END_IF;

// 2. 单位标准化
#27 := STD(#24);
#28 := STD(#25);

// 3. 模式备份
#30 := #1004;
#31 := #1015;

// 4. 主体逻辑
G91;
G01 X#27 Y#28 F#9;
WAIT();
#32 := #1321;

// 5. 模式还原
G#31;
G#30;

// 6. 返回
M99;
```
