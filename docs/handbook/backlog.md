# 新代 MACRO 语法规范手册 · 待落地与待确认

> 本文件为 [MACRO 语法手册](README.md) 的分册（诊断规则 backlog 与待确认项）。
> CF 检索状态以 [能力矩阵](../MACRO能力矩阵.md) 为准；CF 未在官方页面找到的项目保持待确认，不进入强诊断。

## 待落地优先级

1. `G10 L1000` / `G10 L1021` / `G10 L1022` / `G10 L1803` / `G10 L1805` / `G10 L1810` / `G10 L1820` / `G10 L1910` / `G10 L1911` 静态范围检查；`L1900/L1901` 其余未确认上限不做臆测校验。
2. `G04.102 I` 静态范围检查。
3. `STITCHON/WEAVEON` 更完整的静态范围检查。
4. `MOD` 明显 Double 操作数检查。
5. `AXID/STDAX` 字符串轴名 warning。
6. `OPEN("COM1")` warning。
7. `ALARM/MSG` 静态 ID 和字符串长度检查。
8. `#0` / `@0` 作为赋值目标 warning。
9. 固定编号 `#401` 以上依变量区间提示用途或风险。
10. 扩充引数数字后缀合法性检查，例如 `D1`、`P1` 报错提示。
11. 公用变量 `@` 固定编号区间提示：R 寄存器映射区、断电记忆区、CE 扩充区。
12. 静态可判定的 R 寄存器系统保留区写入 warning。
13. 字符串写入公用变量时提示 ASCII 转码与 `SCANTEXT` 读取规则。
14. AR/MAR 固定编号负数、小数诊断。
15. AR/MAR APP Macro 路径诊断：非 `DiskC\app\%AppName%\bin\Macro\` 路径提示 `COR-016` 风险。
16. 读取 `app.acfg` 后对 AR/MAR 固定编号做容量范围检查。
17. AR 字符串写入与 APP Macro 中 `SCANTEXT` 读取规则提示；MAR 字符串写入提示不支援。
18. 运算式复杂度与嵌套深度提示，对应 `COM-005` / `COM-007` 风险。
19. G 码引数运算提示：括号可省略但复杂表达式建议加括号。
20. IF / CASE / REPEAT / WHILE / FOR 单档组数上限提示。
21. 单组 `ELSEIF` 与 CASE 条件语句数量上限提示。
22. FOR 循环内跳转进出风险提示：`G72` ~ `G78`、往返 `GOTO`、`M98 H_`。
23. 缺少分号的版本差异提示，尤其 10.120.45 ~ 10.120.60 的 `COM-008` 风险。
24. `GOTO` 无穷循环风险提示，建议循环中加入 `SLEEP()`。
25. 路径扩充引数诊断：允许 `,C_`、`,R_`、`,A_`，未确认引数如 `,Z_` 提示 `COR-034` 风险。
26. 预解风险提示：运动后立即读取座标或状态时建议加入 `WAIT()`。
27. 宏程序内改变 `G90/G91`、座标系或 `#1000` 时提示备份与还原风险。
28. 大档案范围语法跨页与动态建表降速风险提示。
29. 同一单节 G 码宏程序 / M 码宏程序 / 插值码引数占用顺序提示。
30. MACRO 撰写模板检查：缺少 `M99`、未还原模态、运动后读状态未 `WAIT()` 等风险提示。
31. `L` 引数特殊值提示：未指定为 `L1`，`L0` 不执行。
32. 客制参数只读区间 hover 与写入 warning。
33. 扩充 G 码 / 登录 G 码 / 登录 M 码 / T 码宏程序文件名规则诊断。
34. 登录 M 码系统保留码检查：`M00`、`M01`、`M02`、`M30`、`M96`、`M97`、`M98`、`M99` 不可登录。
35. 登录 M 码执行后引数占用提示：除 T 码外所有引数视为占用。
36. 同一单节多个 M 码宏程序只执行第一个、多个 G 码宏程序只执行最后一个的提示。
37. `Pr3598` M 码引数模式对 `#13` 的影响提示。
38. 登录 G 码宏程序内改变 `#1000` 未还原的风险提示。
39. 数学函数静态域检查：`ATAN2(0,0)`、`POW` 负基底、`LN` 非正数。
40. `PARAM`、`CHKINF`、I/O 读写函数参数型态与范围检查。
41. `SYSDATA` / `DRVDATA` 前缺少 `WAIT()` 的预解风险提示。
42. `READDI` / `READDO` / `READABIT` / `READRREGBIT` 预解减速风险提示。
43. `SETDO` / `SETABIT` / `SETRREGBIT` 与 PLC 混用风险提示。
44. `PRINT` 字符串逃脱字符与小数位 `[n]` 格式高亮 / hover。
45. DB 函数图形模拟固定回传 0 的提示。
46. `ALARM` / `MSG` 自订警报字串档路径 hover。
47. `SETDRAW` BGR 颜色码 hover。
48. 维持 `MOVJ-II` / `INCMOVJ-II` 非正式指令诊断，同时补齐 `MOVJ` / `INCMOVJ` 第二语法与替代语法识别。
49. 移动附加指令范围检查：`FJ/FEJ/FL/FR`、`ACC/DEC`、`PL/PQ/PR`。
50. `WAITSYNC/ENDSYNC`、`CIRMODE`、`G142.101/G142.102` 等机器人指令补全、hover 与诊断。
51. 机器人互斥关系完整诊断：`WAITSYNC`、`G192.1`、`SHIFTON` 与 `STITCHON/WEAVEON` 区间规则。
52. RBT 警报码 hover：`RBT-102`~`RBT-327`、`RBTWRN-010`、`RBTCRI-011`。
