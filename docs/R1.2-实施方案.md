## §6. Rollback 步骤（如 v4.0.0 上线后发现重大问题）

### 选项 A — PR 未发版前回退

```powershell
git revert <R1.2 PR merge commit>
git push origin main
# CI 跑全绿后回归到 v3.1.0 状态
```

### 选项 B — v4.0.0 已发版后回退到 v3.1.0

```powershell
# 1. 删除 v4.0.0 Release 与 tag
gh release delete v4.0.0 --yes --repo SYNTEC-40101720/syntec-macro
git push origin :v4.0.0
git tag -d v4.0.0

# 2. 回滚代码到 v3.1.0
git checkout v3.1.0 -- package.json package-lock.json README.md CHANGELOG.md
git checkout v3.1.0 -- src/  # 恢复 12 模块

# 3. 重打 VSIX 发 v3.1.1 hotfix（按 docs/3.x-Release-Runbook.md §2-§6）
npm.cmd run package
# 必要时 git tag v3.1.1 + git push origin v3.1.1 触发 release.yml
```

### Rollback 后必跑门禁

- `npm test` (期望 490/490 PASS for v3.1.0 baseline)
- `npm run lint`
- `npm run check:release -- --tag v3.1.1`
- `npm run check:js-backend-retirement` (v3.1.0 应跳 item 7 stale marker)
- `npm run smoke:installed`
