# 运行时验证程序

本目录包含需在模拟器或控制器上执行的验证程序，对应 [MACRO 知识与验证规划](../../docs/macro-knowledge/MACRO知识与验证规划.md) 的运行时验证项。

## 使用方式

1. 将文件上传到控制器加工目录（文件无后缀，直接使用）
2. 所有文件放在同一目录，新代控制器不支持子目录分层
3. 执行主程序，加工结束后查看 @ 变量值
4. 按记录模板记录结果

## 文件说明

| 前缀 | 验证项 | 文件 |
|---|---|---|
| CALL_RUN_ | CALL-RUN-01~07 调用语义 | 9 主程序 + 9 子程序 (O 开头) |
| FUN_D_ | FUN-D-01~03 Cycle DB | 3 程序 |
| FUN_E_ | FUN-E-06/07 单位与堆栈 | 2 程序 |
| FUN_F_ | FUN-F-03/04 图形模拟 | 2 程序 |

## 记录模板

每项验证需记录：
- 验证 ID
- 控制器机型
- 软件版本
- 参数状态
- 完整程序
- 实际结果
- 截图/日志
- 结论与风险
